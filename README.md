# clock-builds-for-windows
Всех приветствую, это мой первый гит, который я сделал сам. Гит представляет из себя небольшие экранные часы, которые можно увеличивать/уменьшать, а также перемещать. Написан на интерпретаторе питона, поэтому нужен будет python 3.14 либо др версии.
Буду очень рад если Вы оцените данный гит, любой комментарий сочту за отзыв!
